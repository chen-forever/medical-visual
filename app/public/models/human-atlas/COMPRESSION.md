# 模型压缩记录

## 结果

| 指标 | 压缩前 | 压缩后 |
|---|---|---|
| 模型目录 | 约 34.3 MB | 约 11.9 MB |
| 几何 gzip | 31.4 MB / 15 分块 | **10.37 MB / 1 分块** |
| 三角形 | 约 128 万 | 约 64.7 万 |
| 首次请求 | 33 MB 级 | 约 11.4 MB（atlas 1.05 MB + 几何 10.37 MB） |

## 保留内容

- 体表（integumentary）
- 骨骼（skeletal）
- 肌肉（muscular）
- 五脏六腑 10 个器官：胃、胆、小肠、大肠、膀胱、心、肺、肝、脾、肾

已移除当前界面不展示的脑、血管、神经及其他系统几何，后续如需血管/神经，应单独做按需包。

## 方法

1. 只保留上述基础层和 10 个器官对应的 source parts；
2. 用 `meshoptimizer` 按部位简化：
   - 体表 46%
   - 骨骼 40%
   - 肌肉 30%
   - 器官 50–70%
3. 顶点压缩后重新打包为单个 `body-core.bin.gz`；
4. 使用 gzip level 9；
5. 保留原 `atlas.json` 的 FMA 概念与器官映射，压缩只改变 geometry 和 chunk 布局。

## 视觉取舍

- 体表/骨骼/肌肉轮廓保持，远看无可见变化；
- 器官形状保留，局部细节减少；
- 透明度沿用上一版设置，未为了让模型变小而改变透明度；
- 如果需要更高精度，可只提高某个器官的简化比例，重新生成。

## 注意

- 原完整模型在 Git 历史中仍可找回；当前工作树只保留精简包。
- 该文件记录的是当前分支的压缩结果，不代表基线 tag。
